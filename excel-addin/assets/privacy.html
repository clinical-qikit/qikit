QI Kit for Excel: privacy and security

For users and for IT reviewers. Describes the version published beside this page; each vX.Y.Z/ folder carries its own copy.

QI Kit does all of its calculation inside Excel, on your computer. It sends no workbook data anywhere. It has no server of its own, no telemetry or analytics, no accounts or sign-in, and sets no cookies.

What is downloaded, and from where

  • The task pane's own files (one HTML page, scripts and icons) come from the folder the manifest names: clinical-qikit.github.io/qikit/ on GitHub Pages, or your organization's server if it hosts its own copy. GitHub serves them like any website: it sees a request for the files, not your data.
  • Office.js, Microsoft's library that every Office add-in uses to talk to Excel, comes from appsforoffice.microsoft.com. What Office.js itself sends to Microsoft is covered by Microsoft's privacy statement, as it is for any add-in.

Nothing else is loaded. After the page has loaded, the add-in's own code makes no network requests. The page enforces this with a Content Security Policy: the browser refuses scripts from anywhere but the add-in's own folder and Microsoft's Office.js address, and refuses network requests from the add-in's code to any address except its own folder.

What it reads and writes in your workbook

  • Reads the cells you select when you click a button such as Use Current Selection, and nothing else, except ranges you have linked for live updates (below).
  • Writes only new sheets it creates for its output (charts, tables, experiment templates, the sample data), and the charts on them. It does not change your existing cells. Its manifest asks for read and write access to the document (ReadWriteDocument) because it needs to create those sheets.
  • Live updates: when you write a chart to a sheet, the add-in links its source range so the chart recomputes when the data changes, rewriting that output sheet (one the add-in created) and nothing else. The list of links is stored in the workbook's own add-in settings (qikit.liveUpdates), so it travels with the workbook.
  • Remembered choices: the SPC panel stores its chart type and options in the workbook's add-in settings (qikit.spc.settings). No cell values are stored there.

When something goes wrong

An error message offers Copy details: the add-in version, the panel, the error text and technical trace, and the Excel and browser versions. It copies them to your clipboard and sends nothing. You decide whether to paste them anywhere, such as a GitHub issue. Read them first: an error message can include a column name from your sheet.

Reviewing it

  • The source is open: github.com/clinical-qikit/qikit (the add-in is in excel-addin/). Each published folder is built from a tagged release by a public GitHub Actions workflow.
  • To pin a reviewed version, use a vX.Y.Z/ folder instead of latest/. Those folders never change once published.
  • To host it yourself, build excel-addin/ and serve dist/ from your own server. The install guide explains how.
  • Report problems as an issue. For a security problem, open an issue asking for a private contact instead of describing it in public.
